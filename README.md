## Featured Projects

### 🔍 [RAG Intelligence Platform](https://github.com/rajapalagummi/RAG-Intelligence-Platform)
Hybrid BM25 + vector + LLM retrieval pipeline with contradiction detection across regulatory documents. RAGAS self-evaluation per query. 5 live APIs. No paid infrastructure.
`Python` `LangChain` `ChromaDB` `Mistral` `BM25` `Docker`

---

### 💸 [AML Transaction Detection](https://github.com/rajapalagummi/AML-Detection)
PySpark ML pipeline on 5M+ real financial transactions. GBT AUC 0.9801, precision 90.2% at 0.10% class imbalance. NetworkX graph analysis detecting Fan-Out, Fan-In and Cycle laundering patterns.
`Python` `PySpark` `MLlib` `NetworkX` `IBM AML Dataset`

---

### 🧬 [NHANES Sleep & Mental Health Biomarker Analysis](https://github.com/rajapalagummi/NHANES-Sleep-Mental-Health)
Longitudinal pipeline merging 6 CDC modules across two survey cycles — 11,848 US adults. Found BMI and alcohol use are stronger biological correlates of depression than sleep (p<0.0001, Cohen's d=0.228).
`Python` `SciPy` `Scikit-learn` `pyreadstat` `CDC NHANES`

---

### 🤖 [MLOps Lifecycle Engine](https://github.com/rajapalagummi/MLOps-Lifecycle-Engine)
Champion model AUC 0.9830. PSI + KS + Jensen-Shannon drift detection across 10 features. Automated F1 degradation alerts (0.940 → 0.547). MLflow experiment registry. Docker Compose deployment.
`Python` `MLflow` `SHAP` `Scikit-learn` `Docker`

---

### 🎬 [Behavioral Signal Engine](https://github.com/rajapalagummi/Behavioral-Signal-Engine)
User engagement profiling on 100,836 real MovieLens ratings. SVD collaborative filtering RMSE 1.7885. Content-based MAE 0.8384 vs collaborative 1.3473 — A/B validated at p=0.0000 across 200 users.
`Python` `Scikit-learn` `SciPy` `SVD` `MovieLens`

---

### 🔒 [Autonomous Code Review Agent](https://github.com/rajapalagummi/Code-Review-Agent)
6-agent pipeline that clones any public GitHub repo, runs Python AST + SQL static analysis, generates LLM-powered fixes and pytest test suites. Zero paid APIs. Local Ollama inference.
`Python` `Ollama` `LangChain` `AST` `Multi-agent`
